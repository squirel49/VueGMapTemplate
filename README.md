This is the template code for an Ionic Vue google maps frontend.

If all that is needed is the google maps component, it can be found in src/views/GMap.vue.


To run locally:

Create a google maps api key: 
https://console.cloud.google.com/google/maps-apis

Insert it into GMap.vue component at line 72.


install ionic
https://ionicframework.com/docs/intro/cli

ionic serve


Current the template is set to use the pathsapi backend.
Change to local backend within Home.vue at line 134/135.
